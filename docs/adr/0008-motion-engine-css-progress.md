# 0008. Свой движок анимаций на переменной `--p` вместо GSAP; `data-motion` и `data-anim`

## Контекст

Эталон стиля halalcash построен на Lenis, одном rAF, записывающем прогресс в CSS-переменную, и хореографии в CSS через `calc/clamp`. Требования такие: «каждый раздел живой», но на телефоне и при «уменьшить движение» ничего не должно тормозить и укачивать. Мобильный аудит (G10) показал, что при единственном флаге телефон получается мёртвым.

## Решение

`ui/motion` — это Lenis (lerp .1) и один rAF, который пишет `--p` (0…1) в наблюдаемые элементы, плюс IntersectionObserver для включения элементов и одноразового `data-revealed`. Вся хореография живёт в CSS. Движение разведено на два флага на `<html>`:
- `data-motion='on'` — scroll-scrub (всё, что зависит от `--p`): pinned-секции, сцена, параллакс. Выключен на `(pointer:coarse)` и при `prefers-reduced-motion`. CSS от `var(--p)` пишется только под этим флагом.
- `data-anim='on'` — анимации без привязки к скроллу: reveal по IO, marquee, вход hero, HandStroke, вращение розетты. Включены везде, кроме reduced-motion.

## Почему

- **GSAP + ScrollTrigger.** Отвергнуто: формулы эталона пришлось бы переписывать в JS-таймлайны, и хореография разошлась бы между CSS и JS. Кроме того, это тяжёлая зависимость ради того, что один rAF и CSS делают сами.
- **Один флаг «движение вкл/выкл».** Так было сначала, и вариант отвергнут по итогам аудита: на тач-устройствах выключались и дешёвые, безопасные анимации, и мобильная версия выглядела статичной. Scroll-scrub на таче дёргается, а reveal и marquee — нет, поэтому флаги разделены.
- **Scroll-driven animations CSS (`animation-timeline`).** Отвергнуто: поддержка в Safari и Firefox неполная, а Lenis со сглаживанием с ними не сочетается.

## Последствия

- Каждое новое правило анимации нужно отнести к одному из двух флагов. Ошибка даёт либо дёрганье на телефоне, либо мёртвый блок. Это правило держится только на дисциплине.
- Lenis перехватывает прокрутку: якоря, `scrollTo`, блокировка скролла под модалками и лайтбоксом идут через API движка (`lockScroll`, `scrollToTop`), а не через нативные средства.
- На таче pinned-главы превращаются в горизонтальную ленту со scroll-snap и точками. Это отдельная вёрстка, и её надо поддерживать параллельно с десктопной.
