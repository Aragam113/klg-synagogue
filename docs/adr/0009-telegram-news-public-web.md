# 0009. Новости из Telegram через публичную веб-версию канала, безопасный fetch с allowlist хостов

## Контекст

Пользователь попросил наполнить новости постами канала https://t.me/B_C_Kaliningrad за последние пару месяцев. В постах альбомы картинок. Доступа к управлению каналом и ключей API нет. Импорт должен повторяться без дублей.

## Решение

Скрипт `npm run import:telegram -- --since YYYY-MM-DD` читает публичную веб-версию `t.me/s/<канал>` (пагинация `?before=`, при недоступности — фолбэк через r.jina.ai) и разбирает HTML. Одно сообщение веб-версии становится одной новостью: текст дословно, только ru; картинки альбома перекодируются в webp и сохраняются в uploads; обложка — первая картинка; ссылка на исходный пост указывается. Идемпотентность держится на уникальном `news.source_url`. Все сетевые запросы, включая скачивание картинок по URL из разобранного HTML, идут через безопасный fetch, который пропускает только хосты из allowlist.

## Почему

- **Telegram Bot API.** Отвергнуто: бота нужно сделать админом канала, а это доступ, которого нет. К тому же бот получает только новые посты, а не историю за два месяца.
- **MTProto-клиент (Telethon/GramJS).** Отвергнуто: нужен вход по номеру телефона, `api_id` и сессия-секрет, которые придётся хранить. Для чтения публичного канала это несоразмерно.
- **Перенести посты вручную через админку.** Отвергнуто: это 93 поста и 311 картинок, и повторить такое владелец не сможет.
- **Обычный fetch без ограничений.** Отвергнуто: URL картинок берутся из чужого HTML (или из ответа стороннего прокси). Без allowlist скрипт можно заставить ходить во внутреннюю сеть или скачивать что угодно в uploads.

## Последствия

- Это скрейпинг вёрстки: если Telegram поменяет разметку `tgme_widget_message_*`, импорт сломается. Unit-тесты на сохранённых фикстурах поймают поломку парсера, но не изменение живой страницы.
- Импорт запускается вручную, расписания нет, так что новые посты сами на сайт не попадают.
- Фолбэк r.jina.ai — сторонний прокси, через который проходит трафик. Если он понадобится, его хост тоже должен быть в allowlist. Новый источник картинок (другой CDN Telegram) потребует правки списка.
- У импортированных новостей нет en/he: на других языках они показываются по-русски с пометкой (ADR 0006).
