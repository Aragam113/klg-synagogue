## Логотип общины

- `brand/synagogue-logo.svg` — оригинальный логотип из предоставленного общиной файла «лого синагога син.pdf», экспортирован в SVG 16.11.2026. Геометрия и надпись сохранены в векторных контурах, шрифты и растровые изображения не используются.
- `brand/synagogue-logo-light.svg` — та же геометрия в белом цвете для тёмного фона. Иконки браузера генерируются из этого же логотипа командой `npm run build:favicon`.

- `brand/synagogue-mark.svg`, `brand/synagogue-mark-light.svg` — компактный знак для шапки: архитектурная часть оригинального логотипа (99 исходных контуров) без внешней рамки и мелкой надписи. Геометрия здания и толщина линий сохранены; полная эмблема используется в подвале.
