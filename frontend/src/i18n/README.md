# i18n

- Языки: `ru` (источник, фолбэк), `en`, `he` (RTL).
- Неймспейс = файл `locales/<lang>/<namespace>.json`. Подхватывается автоматически (`require.context` в `index.ts`) — свой неймспейс кладите тремя файлами, `index.ts` не трогайте.
- В компоненте: `const { t, lang, dir } = useLang('schedule')`; ключи общего неймспейса — `t('common:nav.news')`.
- Выбор языка: `?lang=` в URL → сохранённый (`synagogue.lang`) → `ru`. На `<html>` ставятся `lang` и `dir`.
- **Иврит — машинный перевод, нужна вычитка носителем.** Все `he/*.json` до вычитки считаются черновиком.
