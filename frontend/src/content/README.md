# src/content

Длинные тексты разделов (абзацы, главы истории, правовые страницы) живут здесь, в типизированных `{ru,en,he}/sections.ts`: у абзацев есть комментарии-источники `src:` и их проверяет тест паритета языков. Короткие подписи интерфейса (кнопки, заголовки колонок, дни недели) — в i18n `src/i18n/locales/<lang>/sections.json`. Факты (телефоны, часы, цены) — только в `src/config/site.ts`; название сайта — `common:site.name`. Один ключ живёт ровно в одном месте: текст не дублируется между `content`, `sections.json` и `site.ts`.
