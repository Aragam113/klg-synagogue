# Сайт синагоги Калининграда — запуск на своём компьютере

## Что нужно

- **Node.js 20.19 или новее** (LTS с https://nodejs.org). Больше ничего: PostgreSQL встроенный, Docker не нужен.
- **Интернет при первом запуске** — скачиваются зависимости (~1 ГБ вместе с PostgreSQL). Дальше работает без сети.
- Windows 10/11 (x64), macOS (Intel или Apple Silicon) или Linux x64.

## Запуск — одна команда

```
npm start
```

Или двойной щелчок по `start.cmd` (Windows) / `./start.sh` (macOS, Linux).

Первый запуск занимает 3–5 минут: ставит зависимости, поднимает встроенный PostgreSQL в `.devdata/pg` (для папки с русскими буквами — см. «Если что-то пошло не так»),
восстанавливает данные из `dev-data/db.sql`, создаёт `backend/.env` и копирует картинки. Повторный запуск
поднимается за ~1 минуту, ничего не переустанавливая.

Когда всё готово, откроется браузер, а в консоли будут адреса:

- **Сайт** — `http://localhost:8081` (если порт занят — следующий свободный);
- **Админка** — `<адрес сайта>/admin`;
- **Swagger** — `http://localhost:3000/docs` (или следующий свободный порт);
- PostgreSQL — порт 54329 или следующий свободный.

Остановить всё, включая базу: **Ctrl+C** (если Windows спросит «Завершить выполнение пакетного файла?» — ответьте Y).

## Вход в админку

Логин `admin@dev.local`, пароль случайный: он печатается в консоль при первом запуске и сохраняется в
`DEV-LOGIN.txt` в корне. Новый пароль — удалить `backend/.env` и запустить `npm start` заново.

## Сброс данных

```
npm run reset
```

Возвращает базу и картинки к состоянию дампа (всё, что изменено в админке, пропадёт). Потом — `npm start`.

## Что в данных

95 новостей из Telegram-канала общины, программы, подразделения, альбомы, расписание молитв и **демо-записи**:
6 событий афиши и 4 сбора с плашкой «Пример» — они показывают, как выглядят разделы, и не являются фактами
общины. Даты демо-афиши раз в день пересчитываются от сегодняшнего дня. Убрать их:
`cd backend && npm run seed:demo -- --remove`, вернуть — `npm run seed:demo`.

Оплата — тестовая (fake): кнопка «Оплатить» ведёт на страницу-заглушку, деньги не списываются.

## Обновить новости из Telegram

Пока сайт запущен (`npm start`), во втором окне терминала:

```
cd backend
npm run import:telegram -- --since 2026-10-01
```

Дата — день последнего импорта; дубли не создаются. Новые картинки лягут в `backend/uploads`.

## Если что-то пошло не так

- «Нужен Node.js ≥ …» — обновите Node до LTS.
- **Папка с русскими буквами или в OneDrive** (например `Рабочий стол`). Встроенный PostgreSQL не понимает
  такие пути, поэтому `npm start` сам кладёт его данные в отдельную папку
  `%LOCALAPPDATA%\klg-synagogue-dev\<код папки проекта>` (macOS/Linux: `~/.klg-synagogue-dev/...`).
  Бинарники PostgreSQL один раз копируются в `...\klg-synagogue-dev\pg-bin` (~100 МБ). В консоли будет
  строка «Создаю кластер PostgreSQL в … (путь проекта не ASCII или в OneDrive)». Это нормально.
  Если всё равно ошибка, перенеси папку в путь без русских букв, например `C:\dev\klg-synagogue`.
  Ещё вариант: задай `KLG_DEV_HOME` — папку без русских букв для данных PostgreSQL
  (`set KLG_DEV_HOME=C:\dev\klg-cache` перед `npm start`).
- Ошибка PostgreSQL — лог в `.devdata/pg.log` (или `pg.log` в папке из пункта выше); крайний случай — `npm run reset`.
  `npm run reset` чистит именно ту папку, где лежат данные.
- Сайт открылся без данных — подождите, пока в консоли появится «Готово!», и обновите страницу.
- Подробности по коду и командам — `frontend/README.md` и комментарии в начале скриптов `scripts/`.
